# Геометрия • 8 класс — 2.0

Офлайн-приложение на русском для Android 6.0+ (API 23). Без аккаунта, интернета, рекламы и покупок.

**[Скачать APK 2.0](https://raw.githubusercontent.com/Vithel2/8klassgeometry./abcd354a42f9546bfbe46e809f2bfca8bbfc774b/downloads/geometry-8.apk)** · [Страница выпуска](https://github.com/Vithel2/8klassgeometry./releases/tag/v2.0)

Приложение изменено: `versionName=2.0`, `versionCode=4`. Это новая сборка с новыми исходниками, а не старый APK.

## Установка и старый прогресс

APK подписан отладочным сертификатом. Подпись отличается от старого `downloads/geometry-8.apk`: старый закрытый ключ отсутствует в исходном репозитории. Android не разрешит установить эту сборку поверх старой. Если старая версия установлена, для установки 2.0 потребуется удалить её; это удалит её локальный прогресс. На телефоне друга без старой версии APK устанавливается обычным способом.

Новый код читает прежний ключ `geometry8` и прежнюю тему `geometry8-theme`, не обнуляя корректные данные. Совместимость формата проверена браузерным тестом; перенос установленного Android-приложения при разных подписях невозможен. Автоматическая подпись будущих сборок постоянным ключом через Actions secrets не настроена: подключение GitHub возвращает HTTP 403 при доступе к secrets. Ключи не публикуются в репозитории или Release. Автоматические CI-сборки используют стандартную debug-подпись своего runner и могут отличаться сертификатом от опубликованного APK.

## Что работает

- 20 тем: все 19 тем ТЗ и сохранённая отдельная тема свойств фигур. Для каждой — правило, SVG-схема, пример, ошибка и запуск практики. Все шесть задач из тетради включены точно, включая различие всей средней линии, её частей от одной диагонали и промежутка между двумя диагоналями.
- Пифагор: гипотенуза и оба катета, диагональ прямоугольника, сумма/разность квадратов, извлечение корня, проверка.
- Поиск, отметки изученного, переворачиваемые карточки формул, сохранённый помощник подстановки в формулы.
- Разминка с вариантами; самостоятельный и сложный режимы без вариантов; 10 задач за 15 минут. Новые числа при повторе, несколько числовых полей в комбинированных задачах, поэлементная проверка. Геометрически допустимые данные, включая исправленный старый генератор высот.
- Поле «Моё решение», черновики, восстановление незавершённой сессии после закрытия; текст рядом с образцом в истории. Числовая проверка явно отделена от проверки доказательства. Принятые ответы считаются один раз, даже при выходе.
- Обычный калькулятор внутри занятия: скобки, четыре действия, квадрат, корень, десятичная точка/запятая; сообщения об ошибках. Рекурсивный парсер без динамического исполнения кода. Принимаются точные выражения с корнем и округление до сотых.
- Диалог выхода в интерфейсе: продолжить/выйти, переключение вкладок и Android Back. При истечении таймера закрываются калькулятор и диалог; таймер останавливается. Уже принятые ответы сохраняются.
- Статистика, 40 последних попыток (включая прерванные), 40 ошибок и похожие задачи по теме.
- Стеклянные панели и плавающая навигация. Светлая/тёмная/системная тема, 4 акцента, 3 размера текста, 3 интенсивности стекла, отключение анимаций и уважение системного reduced motion, тактильный отклик.
- Три настоящих launcher alias: угол, прямоугольный треугольник и ромб. Нативный мост включает выбранный alias и выключает остальные, сохраняя доступный launcher.
- Сброс прогресса с диалогом и видимая версия. В манифесте нет разрешения INTERNET, сетевые загрузки WebView запрещены.

Устные задачи о свойствах доступны в разминке; числовые темы — во всех режимах.

## Выполненные проверки

1. `npm test`: 5 групп — 6000 генераций для 20 тем, 3800 независимых пересчётов числовых ответов, повторяемость с новыми числами, допустимость высот, все примеры тетради; Пифагор 3–4–5, 13–5–12, 10–6–8; парсер, корни и округление.
2. Playwright + Chromium: ширина 320, 390 и 768 px с очень крупным текстом; темы, поиск, сохранение прогресса и настроек, миграция старого формата; разминка, полный тест, отдельная проверка нескольких величин, черновики, история, калькулятор и помощник формул, выход/отмена/JS-обработчик Android Back, таймер поверх калькулятора и диалога, reduced motion. Без ошибок JavaScript.
3. `:app:assembleDebug :app:lintDebug`: успешно, 0 ошибок Lint; 2 ожидаемых предупреждения — включённый JavaScript для локального интерфейса и атрибут Android 13 при поддержке старых API. AGP 8.7.3, Gradle 8.9, compile/targetSdk 35, build-tools 34.0.0. Локальная сборка JDK 21; CI сохраняет JDK 17.
4. `apksigner verify`: подпись v1/v2 корректна. `aapt`: пакет `ru.geometry.trainer`, версия 2.0, код 4; в итоговом манифесте три alias и правильные ресурсы иконок.
5. `tests/verify-apk.py`: каждый asset в APK побайтно совпадает с актуальным исходником, в том числе интерфейс настроек, engine и темы Пифагора. Браузерные проверки повторены на файлах, извлечённых непосредственно из APK.
6. После публикации публичный APK скачан по прямой ссылке без авторизации и сверен по SHA-256 с проверенным файлом. `downloads/geometry-8.apk` заменён тем же файлом.

**На настоящем Android и эмуляторе приложение не запускалось.** В среде нет подключённого устройства и `/dev/kvm`. Нативное отображение WebView, смена значка конкретным launcher, тактильный отклик, системные жесты и поведение Android при выгрузке процесса требуют проверки на устройстве. Браузерные тесты обработчика Back не заменяют такой запуск.

## Повторение проверок и сборки

```sh
npm ci
npm test
npx playwright install --with-deps chromium
mkdir -p artifacts
python3 -m http.server 8123 --directory app/src/main/assets
# Во втором терминале:
CHROMIUM_PATH=$(node -e "process.stdout.write(require('playwright').chromium.executablePath())") npm run test:ui
# JDK 17, Android SDK 35 и build-tools 34.0.0:
gradle --no-daemon :app:assembleDebug :app:lintDebug
python3 tests/verify-apk.py app/build/outputs/apk/debug/app-debug.apk
```

Основной workflow только один: `.github/workflows/android.yml`. Он проверяет математику и интерфейс, явно устанавливает нужные SDK-пакеты без устаревшего `tools`, собирает и проверяет APK, публикует artifact вместе с Lint-отчётом и скриншотами. Публичный Release 2.0 содержит ссылки на отдельно проверенную сборку и SHA-256 в репозитории. Загрузка бинарного вложения на uploads.github.com отклонена GitHub с HTTP 401, поэтому используется публичная прямая ссылка на файл в зафиксированном коммите.
