# Геометрия • 8 класс — 2.2

**[Скачать APK 2.2 «Новые темы»](https://raw.githubusercontent.com/Vithel2/8klassgeometry./refs/heads/main/downloads/geometry-8-notebook.apk)**

Офлайн-приложение для Android 6.0+, без аккаунта, рекламы и сетевых разрешений. 23 геометрические темы, объяснения и SVG-схемы, примеры из тетради, калькулятор, решения и история.

## Что изменилось

- Случайно присланная информатика полностью удалена из учебного материала и генератора. При обновлении убираются её отметки, ошибки, попытки и незавершённая сессия; геометрический прогресс сохраняется.
- Новый главный экран: геометрическая графика, крупные заголовки, стеклянные поверхности, светлая/тёмная темы и выбранный акцент.
- Эффект по видео: одна растягивающаяся капсула в навигации, пружинное движение и перетаскивание пальцем. Цвет значков и подписей проявляется внутри движущейся капсулы. Кнопки получают блик под пальцем и упругий отпуск.
- Короткий нативный тактильный отклик на кнопках и при смене вкладки во время перетаскивания. Он отключается в настройках; есть кнопка проверки. Реальная вибрация зависит от устройства и системных настроек.
- Длина тренировки от 1 до 100 вопросов: ввод числа и пресеты 5/10/25/50/100 доступны в тренировках и настройках. Выбор сохраняется и действует при запуске из темы и с главной. Тренировка без таймера; пробный тест остаётся на 10 задач за 15 минут.
- После завершения можно сразу повторить занятие той же длины и темы. Незавершённая длинная тренировка восстанавливается после закрытия. История хранит до 40 попыток с ограничением общего объёма, чтобы длинные занятия сохранялись.
- Сохраняются поиск, карточки формул, три значка приложения, черновик решения, калькулятор и работа над ошибками.

## Как установить

`geometry-8-notebook.apk`: пакет `ru.geometry.trainer.notebook`, версия 2.2, код 6. Подпись сохранена от выданной здесь версии 2.1 «Новые темы» — ставится поверх неё с сохранением данных.

Для исходной версии 2.0 из присланного `base.apk` закрытого ключа нет. «Новые темы» устанавливаются рядом с ней и не затрагивают её данные; автоматического переноса прогресса между пакетами нет. Второй APK `geometry-8.apk` использует исходный пакет `ru.geometry.trainer`, но не совместим с подписью присланного 2.0. Не удаляйте его ради обновления, если нужен старый прогресс. Приватные ключи не публикуются.

## Проверки и сборка

JDK 17+ (локально 21), Gradle 8.9, Android SDK 35, build-tools 34.0.0, AGP 8.7.3.

```sh
npm ci
npm test
mkdir -p artifacts
python3 -m http.server 8123 --directory app/src/main/assets
# В другом терминале, с установленным Chromium:
npm run test:ui
npm run test:upgrade
# Основной пакет:
gradle --no-daemon :app:assembleDebug :app:lintDebug
# Вариант «Новые темы»:
gradle --no-daemon -PnotebookInstall :app:assembleDebug :app:lintDebug
python3 tests/verify-apk.py app/build/outputs/apk/debug/app-debug.apk
```

`CHROMIUM_PATH` задаёт путь к Chromium для браузерных тестов, `BASE_URL` — адрес локального сервера.

Проверяются математика и корни, обе сборки и Lint, соответствие каждого asset исходнику и подпись. Браузерные тесты покрывают выход, таймер, восстановление, калькулятор, настройки, полный цикл 100 ответов с перезагрузкой на середине, повтор, диапазон 1–100, миграцию без логики, перетаскивание капсулы, вызовы моста тактильного отклика и его отключение, reduced motion и ширины 320/390/768 px. Системное отключение анимаций учитывается.

На физическом Android или эмуляторе сборка не запускалась. Проверка вызова моста не измеряет физическую вибрацию. SHA-256 обоих опубликованных файлов — в `downloads/SHA256SUMS`; проверенный APK скачивается обратно и сверяется с локальным файлом.
