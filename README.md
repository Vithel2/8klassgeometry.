# Геометрия • 8 класс

**[Скачать готовый APK для Android](https://github.com/Vithel2/8klassgeometry./raw/refs/heads/main/downloads/geometry-8.apk)**

Если браузер открыл страницу файла, нажмите **Download raw file**. Это уже собранное приложение; ждать Actions для установки не нужно.


Офлайн Android-приложение на русском для подготовки по фотографиям тетради: прямоугольник, параллелограмм, ромб, квадрат, трапеция, средняя линия, площади и высоты треугольника.

- 10 коротких уроков с SVG-схемами, примерами и типичными ошибками.
- Тренировка: 5 задач, выбор темы, новые числа и объяснение после ответа.
- Пробный тест: 10 задач по всем темам, 12 минут, разбор в конце.
- Последние 40 ошибок и повторение похожих задач.
- Формулы, калькулятор с подстановкой, прогресс на устройстве.
- Без сервера, аккаунта, рекламы, внешних библиотек и разрешения на интернет.

## Скачать APK через GitHub Actions

1. Загрузите **содержимое этой папки**, включая `.github`, в корень своего GitHub-репозитория (ветка `main` или другая).
2. Откройте **Actions → Собрать APK**. Workflow запускается при push и вручную кнопкой **Run workflow**.
3. После успешной сборки откройте запуск. В разделе **Artifacts** скачайте `geometry-8-apk`.
4. Распакуйте ZIP, перенесите `app-debug.apk` на Android (6.0+) и откройте его. При необходимости разрешите установку приложений для браузера/файлового менеджера, из которого открывается APK.

Это APK для личной установки, подписанный отладочным ключом, а не релиз для Google Play. На разных машинах ключи могут отличаться: для обновления приложения с другого ключа может потребоваться удалить предыдущую версию, что удалит прогресс. Для постоянных обновлений настройте отдельную release-подпись, не храните ключ в репозитории.

## Локальная сборка

Нужны JDK 17, Gradle 8.9, Android SDK Platform 35. Настройте `ANDROID_HOME` или локальный `local.properties` (не коммитить).

```sh
node --test tests/*.test.cjs
gradle --no-daemon :app:assembleDebug :app:lintDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Gradle Wrapper не добавлен; CI устанавливает точную версию Gradle через официальный action.

## Работа над интерфейсом

Откройте `app/src/main/assets/index.html` в браузере. Для разработки не требуется Android SDK. Браузерная версия и APK используют одни и те же локальные HTML/CSS/JS-файлы. Прогресс в браузере и в Android хранится отдельно. После перезапуска приложения прогресс восстанавливается, незавершённая попытка — нет.

- `content.js` — объяснения и примеры.
- `questions.js` — генерация задач и вычисления.
- `app.js` — интерфейс и состояние.
- `tests/math.test.cjs` — проверка 2000 сгенерированных задач и примеров из тетради.
